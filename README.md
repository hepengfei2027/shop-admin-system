电商管理平台（Spring Boot + Vue3）
==================================

本项目为前后端分离的电商管理平台示例：

- 后端：Spring Boot + Spring MVC + MyBatis（纯注解）+ MySQL
- 前端：Vue 3 + Vite + Vue Router + Pinia + Axios + Element Plus

目录结构：

- backend/  后端 Spring Boot 工程
- frontend/ 前端 Vue3 工程

使用方式（简要）：

1. 进入 backend，使用 Maven 导入并启动 Spring Boot 应用（默认端口 8080）。
2. 进入 frontend，安装依赖并启动开发服务器（默认端口 5173）。
